<h2>📖 About the Project</h2>

<p>
Distraction-Free YouTube is a lightweight web interface designed using <b>only HTML5</b>.
The project removes unnecessary visual clutter and focuses on providing a clean video browsing experience.
It is ideal for students, developers, and professionals who want a simple YouTube-inspired interface without distractions.
</p>

---

<h2>✨ Features</h2>

<ul>
  <li>🎥 Clean YouTube-inspired Interface</li>
